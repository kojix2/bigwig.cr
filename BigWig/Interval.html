    struct BigWig::Interval

    • BigWig::Interval
    • Struct
    • Value
    • Object

    Overview

    Coordinates are zero-based; stop is excluded. Returned records retain the original interval boundaries, not boundaries clipped to the query. This remains a value type because readers can emit millions of intervals.
