    class BigWig::Reader

    • BigWig::Reader
    • Reference
    • Object

    Overview

    Reads local/remote bigWig and bigBed files. Prefer BigWig.open with a block. Each iterator has its own traversal and decode buffers. Advancing one iterator cannot invalidate values returned by another.

    def stats(chrom : String, start : Int = 0, stop : Int | Nil = nil, *, type : Symbol = :mean, bins : Int = 1, exact : Bool = false) : Array(Float64) #

    Always returns bins Float64s. Empty bins (including coverage and sum) are NaN. Mean excludes uncovered bases; coverage divides by bin width. std is the sample standard deviation (n-1), with one exact base => 0.

    With exact: false, use the coarsest zoom not exceeding half a bin's width. Partly intersecting zoom records are weighted by overlap/width; minima/maxima may include data just outside the requested bin.
